PRIVACY BY DESIGN

Nothing you have ever leaves your phone.

Most security apps send your files and app list to their servers. Qastellan has no servers to send them to. It downloads a signed threat list once a day and does all the checking on your device.

No account, everInstall it and it works. No sign-up, no email.
No ads or trackingThe app contains no advertising or analytics code, and this site sets no cookies.
Signed, verified updatesThreat lists are cryptographically signed, so a tampered file is rejected.
Open for anyone to checkEvery line of code is public on GitHub.

QUESTIONS

Straight answers.

Is Qastellan really free?

Yes. No ads, no subscription, no premium tier. It costs nothing to run, so it can stay free.

Does anything get uploaded?

No. Apps and files are checked on your phone. Qastellan only downloads its daily threat list; it never sends your data anywhere.

Why does it ask for so many permissions?

To scan apps it must see them, to scan downloads it needs file access, and to warn you it needs notifications. Each one is explained during setup, and you can skip any of them.

How do I install the APK?

Download it on your phone, open it, and allow your browser to install apps when Android asks. You can turn that setting off again afterwards.

Why open source?

Security software asks for a lot of trust. With the code public, anyone can check exactly what Qastellan does.
